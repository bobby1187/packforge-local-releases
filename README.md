# PackForge Local Releases

This public repository stores official PackForge Local desktop installers and automatic-update metadata.

- Application source remains private.
- Download files only from this repository's Releases section.
- Windows updates use the NSIS installer.
- macOS updates use the signed ZIP payload distributed beside the DMG.
- Linux updates use the AppImage.

Release files are generated by the CircleCI workflow in the private `bobby1187/packforge-local` repository.
